# API для перевалов ФСТР

Проект для первого спринта стажировки SkillFactory. API принимает данные о горном перевале и сохраняет их в PostgreSQL.

## Что реализуется

- `POST /submitData` — отправка данных о перевале.
- Сохранение сведений о перевале, авторе, координатах, уровнях сложности и фотографиях.
- Начальный статус модерации — `new`.
