# API для перевалов ФСТР

Проект первого спринта стажировки SkillFactory. API принимает данные о горном перевале и сохраняет их в PostgreSQL.

## Что сделано

- `POST /submitData` — отправка данных о перевале.
- Сохраняются сведения о перевале, авторе, координатах, уровнях сложности и фотографиях.
- Для новой записи автоматически устанавливается статус `new`.
- Данные о перевале и связанных с ним объектах хранятся в отдельных таблицах.
- Настройки подключения к PostgreSQL читаются из переменных окружения.

## Что понадобится

- Python 3.10 или новее.
- PostgreSQL.

## Установка и запуск

1. Склонируй репозиторий и перейди в его папку.
2. Создай и активируй виртуальное окружение.
3. Установи зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создай в PostgreSQL базу данных `pereval` или укажи своё название в настройках.
5. Скопируй `.env.example` в `.env` и укажи данные для подключения к базе.
6. Запусти приложение:

   ```bash
   uvicorn app.main:app --reload
   ```

При запуске приложение создаёт необходимые таблицы. Для локальной проверки API доступна документация FastAPI по адресу `http://127.0.0.1:8000/docs`.

## Настройки базы данных

В `.env` указываются переменные:

- `FSTR_DB_HOST` — адрес сервера PostgreSQL.
- `FSTR_DB_PORT` — порт PostgreSQL.
- `FSTR_LOGIN` — имя пользователя базы данных.
- `FSTR_PASS` — пароль.
- `FSTR_DB_NAME` — название базы данных, по умолчанию `pereval`.

## Метод `POST /submitData`

Пример запроса:

```json
{
  "beauty_title": "пер.",
  "title": "Тестовый перевал",
  "other_titles": "",
  "connect": "",
  "add_time": "2026-10-28 12:00:00",
  "user": {
    "email": "tourist@example.com",
    "fam": "Иванов",
    "name": "Иван",
    "otc": "Иванович",
    "phone": "+79990000000"
  },
  "coords": {
    "latitude": 45.0,
    "longitude": 7.0,
    "height": 2500
  },
  "level": {
    "winter": "1А",
    "summer": "1А",
    "autumn": "",
    "spring": ""
  },
  "images": [
    {
      "data": "данные изображения в виде строки",
      "title": "Вид на перевал"
    }
  ]
}
```

При успешном сохранении API вернёт, например:

```json
{
  "status": 200,
  "message": null,
  "id": 1
}
```

Если обязательные поля не заполнены, возвращается статус `400` с описанием ошибки. Если сохранить данные в базе не удалось, API возвращает статус `500`.
